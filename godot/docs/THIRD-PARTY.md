# Dependências

- Godot Engine 4.6.3: MIT. https://github.com/godotengine/godot/blob/4.6.3-stable/LICENSE.txt
- Vosk API 0.3.45: Apache-2.0. https://github.com/alphacep/vosk-api
- Modelo vosk-model-small-pt-0.3: modelo português oficial; consulte licença e documentação da versão na página https://alphacephei.com/vosk/models e os arquivos preservados no diretório do modelo. O instalador baixa o arquivo original sem modificá-lo.
- python-sounddevice 0.5.1: MIT. https://github.com/spatialaudio/python-sounddevice
- PortAudio: licença MIT/Expat. https://www.portaudio.com/license.html
- PyInstaller: GPL-2.0 com exceção para distribuição dos executáveis gerados. https://pyinstaller.org/en/stable/license.html
- Python 3.11: PSF License. https://docs.python.org/3.11/license.html

Nenhum modelo, imagem, áudio ou código proprietário de LAVOICE é distribuído. Os modelos voxel são construídos por código próprio. O reconhecimento offline não transmite áudio nem requer chave de API. O instalador de modelo faz apenas um download durante a instalação.
